Via

Find the right way.

跨平台的 Wi-Fi 自动切换工具。
首选网络不可用时自动连接备用网络，恢复之后，安静地切回来。

下载最新版本 在 GitHub 查看

macOS · Windows · Linux · Android（预留 iOS 架构占位）

一次联网，就是一次路径选择。 设备不必知道切换发生过多少次，只需要在当下找到合适的那条路。

为什么

把网络切换交给后台

01

自动接管

首选网络不可用时连接备用网络；等它恢复，Via 会自动切回。

02

认得你的选择

如果你在首选网络仍然可用时主动换了网络，Via 会停下自动切换，不和你的决定抢方向盘。

03

安静地待着

菜单栏与托盘里只有一个图标，状态一眼可读；密码保存在系统安全存储中，只留在本机。

工作原理

两条路，一套规则

首选网络
首选网络不可用
备用网络
恢复后切回
  1. 读取当前网络名称，查看附近有哪些网络。
  2. 已经连着首选网络，就只更新状态。
  3. 首选网络不可用时，连接备用网络。
  4. 在备用网络上按设定间隔继续检查，发现首选网络恢复就切回。
  5. 发现你主动换了网络，就关闭自动切换，直到你再次开启。

平台

同一套 Go 引擎，全端一致体验

切换策略、凭据管理与原生界面均基于 Go 与 MyGo 构建，各平台仅通过原生接口完成 Wi-Fi 扫描与切换。

macOS 菜单栏 SF Symbol 图标与自适应 Popover，基于 CoreWLAN / CoreLocation，单条目钥匙串加密存储
Windows 系统托盘与原生界面，基于 WlanAPI，密码存入 Windows Credential Manager
Linux 桌面托盘与浮窗面板，基于 NetworkManager (nmcli) 与 FreeDesktop Secret Service
Android MyGo 原生双视图界面，低打扰常驻守护通知，通过 WifiNetworkSuggestion 优先级切换
iOS 已保留同构原生界面与权限占位，受系统后台联网限制暂不主动切网

各平台受系统 API 限制，扫描、后台监控与主动切换的能力略有差异。详见跨平台说明。
