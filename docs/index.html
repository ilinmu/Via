macOS · Windows · iOS · Android

一次联网，就是一次路径选择。 设备不必知道切换发生过多少次，只需要在当下找到合适的那条路。

为什么

把网络切换交给后台

01

自动接管

优先网络 P 不可用时立即连接备用网络 B；P 回来的那一刻，自动切回去。

02

认得你的选择

如果你在 P 仍然可见时主动切到别的网络，Via 会停下自动切换，不和你的决定抢方向盘。

03

安静地待着

菜单栏与托盘里只有一个图标，状态一眼可读；密码保存在系统安全存储中，只留在本机。

工作原理

两条路，一套规则

P 优先网络
P 不可用
B 备用网络
P 恢复
  1. 读取当前 SSID，扫描周围的网络。
  2. 已经在 P 上，就只更新状态，不做多余动作。
  3. P 不可用且不在 B 上，就连接 B。
  4. 在 B 上按设定间隔继续检查，发现 P 恢复就切回。
  5. 发现你主动换了网络，就暂停监控，直到你再次开启。

平台

同一套策略，四种系统

切换逻辑来自共享的 Rust 策略核心，平台层只负责扫描、连接和呈现。

macOS 菜单栏应用，基于 CoreWLAN，支持完整扫描与主动切换
Windows WPF 托盘应用，基于 WlanAPI，密码存入 Windows Credential Manager
iOS SwiftUI 与 Hotspot Configuration，前台监控网络变化
Android Kotlin 与 Compose，前台服务常驻，通过系统 Wi-Fi 建议切换

各平台受系统 API 限制，扫描、后台监控与主动切换的能力略有差异。详见跨平台说明。
