# Via UI 设计与交互规范

> 适用范围：本文描述 macOS 面板的视觉与交互。iOS 使用系统 `Toggle`、
> Windows 使用系统 `CheckBox`、Android 使用 Material `Switch`；各平台遵循系统
> 控件惯例，但状态语义、术语和文案保持一致。
>
> 设计目标是让第一次使用的用户不看说明书也能完成主链路：允许定位 →
> 选择两个网络 → 开启自动切换。界面只表达用户当下需要做的判断。

## 1. 设计目标

- 用产品本身表达状态：当前连了什么、自动切换开没开、下一次什么时候检查。
- 不在界面里出现 `P`、`B`、`SSID`、策略事件、接口名等内部概念。
- 一个页面只有一个强调色；红色只用于错误，琥珀色只用于需要处理的权限状态。
- 不在主界面重复 Tab 名称，不解释按钮已经说清楚的事情，不弹无意义的确认框。
- 所有数字都要说明含义，并采用易读单位；范围外输入显式提示已调整，而不是悄悄改掉。

## 2. 设计令牌

定义在 `Sources/Via/DesignSystem/PanelPalette.swift`、`PanelTypography.swift`
和 `PanelLayout.swift`，新视图不要直接写十六进制颜色或自定义阴影。

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 强调（填充） | `#2E6B5C` | `#3C7D6C` | 主按钮、开关、分段选中、运行中 |
| 强调（文字） | `#2E6B5C` | `#8CC4B2` | 链接、图标、勾选 |
| 背景 | `#F7F5F1` | `#1B1A18` | 面板、页面 |
| 输入表面 | `#FFFFFF` | `#232120` | 输入框、列表 |
| 分隔线 | `#E4DFD7` | `#3A3733` | 1 px 分隔线 |
| 次级文字 | `#726D65` | `#A8A29A` | 说明、状态、数值 |
| 提醒 | `#A15C00` | `#E0A458` | 权限、未保存 |
| 错误 | `#A33A32` | `#E58C82` | 校验失败 |

强调色取自中国传统色「竹青」的沉静调子，避开橙色、陶土色和后台常见的亮蓝。
灰色全部偏暖；深色模式下强调文字用同色系浅一档，保证与背景的对比度。

字号只有三档，层级靠字重与颜色区分：

| 名称 | 字号 | 用途 |
| --- | --- | --- |
| `PanelFont.title` | 20 / 半粗 | 当前网络名、向导标题 |
| `PanelFont.body` | 13 | 正文、按钮、输入、行标题 |
| `PanelFont.caption` | 11 | 说明、状态、单位、提示 |

间距使用 4 / 8 / 12 / 16，控件高 34，圆角：输入框 8、面板 12。
嵌套圆角按「外圆角减间距」处理；页面默认平，不加阴影、发光或毛玻璃，
阴影只给真正浮起的面板窗口。

## 3. 面板结构

面板固定宽度 400 点，高度随内容测量，最低 360 点，最高取状态栏所在屏幕
可见高度减 24 点，且不超过 680 点。内容超过可用高度时在根滚动区域内滚动。

菜单栏图标左键打开或关闭面板；右键或 Control-点击显示系统菜单，菜单项为
本地化的“退出 Via”，不会打开面板。

顶部固定区域：

1. 小号 Wi-Fi 图标、应用标题。
2. Tab 模式下是三段 Tab 栏，承担全部导航；标题栏右侧不重复放置设置入口。
3. 向导模式下是 `1 / 3` 进度和“跳过”；不显示 Tab 栏。
4. Tab 模式下按需显示提醒横幅：定位权限未就绪、网络设置未完成。

Tab 内容：

| Tab | 内容 |
| --- | --- |
| 状态 | 当前连接、自动切换开关、下次检查、状态说明、两个网络摘要、刷新 |
| 网络 | 首选/备用网络名称与密码、扫描、使用当前网络、保存 |
| 设置 | 登录时启动、语言、检查间隔、使用说明、重新设置、关于、退出 |

Tab 已经写明所处位置，网络和设置页不再重复页标题。

## 4. 状态页

1. `ConnectionSummary`：当前网络名（两行内完整显示）、网络角色或状态说明、
   一个始终带文字的状态徽标。徽标文字用 `.body` 级可读性，颜色只表达语义：
   运行中强调色、等待权限提醒色、已关闭次级灰。
2. 自动切换：系统 `Toggle` + 一行说明。未配置或权限未就绪时禁用，
   由顶部横幅和页内提示给出原因与入口，不留无解释的禁用按钮。
3. 下次检查：运行时用 `TimelineView` 每秒更新。时间统一走
   `LocalizationManager.duration`，显示为「1 分 20 秒」而不是「80 秒」。
4. 状态说明：只在能补充信息时显示，例如已连接备用网络时说明正在等待
   首选网络恢复；一切正常时不重复网络角色。
5. 手动停止：当 `WifiManager.autoSwitchStopReason == .manualOverride` 时，
   显示「你手动切换了网络，自动切换已关闭」和「重新开启」。菜单栏红点因此
   不再是唯一线索，托盘提示也同步说明原因。
6. 两个网络摘要：只读，点击切到网络页；长名称中段省略，不截断含义。
7. 操作只有一个「刷新」。扫描放在网络页，不在状态页重复。

## 5. 网络页

1. 一句说明：连接首选网络；不可用时改用备用网络。
2. `NetworkSetupForm`：扫描行、首选与备用两个编辑器。编辑器包含网络名称、
   可滚动的扫描列表、密码和显示/隐藏按钮；已连接当前网络时提供
   「使用当前网络」，不用手敲名称。
3. 权限不足时扫描禁用并说明原因；手动输入仍可用。
4. 校验错误就近显示在对应字段下方：「请输入首选网络的名称」等；
   两个网络相同显示在表单底部。保存按钮在有改动时始终可点。
5. 扫描结果数量区分单复数（英文 `1 network found` / `%d networks found`）。
6. 底部保存行：未保存/已保存状态、保存按钮，以及一句密码存储说明。

草稿 + 显式保存：输入先写入 `NetworkDraft`，点击保存才提交到 `AppState`；
两个名称去空白后非空且不能完全相同；密码可留空（SSID 区分大小写，与策略核心一致）。切换 Tab 不丢草稿。

## 6. 设置页

1. 通用：登录时启动开关、语言下拉、「使用说明」内联展开、「重新设置」。
2. 自动切换：检查间隔输入框 + 「秒」。输入只允许数字，回车或失焦提交并
   归一化到 5–3600 秒。下方实时显示「每 1 分钟检查一次」；输入越界时改为
   显示「已调整为 5 秒」，不让用户猜测发生了什么。
3. 关于：版本号、仅本机处理的隐私说明、次级色的「退出 Via」。

使用说明只讲三件事：产品会做什么、为什么需要定位权限、手动换网后会发生
什么。不再重复界面导航、状态图标代号或 emoji。

## 7. 首次向导

配置不完整时初始化进入向导。三步：

1. **允许使用定位服务**：解释 macOS 把 Wi-Fi 名称视为位置信息。未决定时
   主按钮「允许访问」，另给「打开系统设置」作为没看到系统提示时的出口；
   已授权显示勾选；仅「使用期间」时说明需要设为「始终」。
2. **设置常用网络**：复用 `NetworkSetupForm`。两个名称有效后才能「下一步」。
3. **准备就绪**：显示两个网络和定位权限摘要。权限就绪时主按钮
   「保存并开启」；未就绪时主按钮改为「打开系统设置」，避免出现一个点了
   没反应、也没有解释的禁用按钮。次按钮「仅保存」始终可用。

第 1、2 步可跳过，进入 Tab 模式并选中网络页；顶部横幅可回到向导。
向导只根据配置完整性判断，不新增持久化标志。

## 8. 无障碍与本地化

- Tab 栏、自动切换开关、语言选择器、密码字段和「使用当前网络」都有
  无障碍标签。
- 状态徽标始终同时提供文字，不只依赖颜色；次级文字与背景对比度不低于
  4.5:1，不再使用过浅的三级灰。
- 长文案按最长期（英文）排布，不缩小字号、不截断；SSID 用两行或中段省略。
- 密码字段保留原生编辑快捷键和右键菜单，明文/密文切换时同步无障碍标签。
- 中英文使用当地系统设置里常见的说法：中文「首选网络／备用网络／允许访问／
  打开系统设置」，英文 `Preferred network / Backup network / Allow access /
  Open System Settings`。英文按钮用句式大小写，不用全大写。
- 全文统一动词：开启/关闭、保存、检查、扫描、打开；省略号用「…」或 `…`，
  不用三个点；不用中间点 `·` 连接内容。
- 缺失本地化 Key 时直接显示 Key 本身；新增文案必须同步补齐中英文。

## 9. 面板高度与滚动

`SettingsView` 用两个 `PreferenceKey` 分别测量固定顶部区域（`chromeHeight`）
和滚动内容（`contentHeight`）：

```swift
totalHeight = max(
    min(chromeHeight + min(contentHeight, metrics.maxHeight - chromeHeight), metrics.maxHeight),
    PanelLayout.minHeight
)
```

- 只测量内容，不测量 `ScrollView` 本身，避免布局循环。
- `PanelMetrics.maxHeight` 由 `AppDelegate` 根据状态栏所在屏幕计算。
- 不做窗口高度动画，避免切换 Tab 时抖动；向导底部按钮随内容滚动可达。

## 10. 实现位置

- 面板外壳、顶部、Tab 栏、横幅、高度测量：`Sources/Via/SettingsView.swift`
- UI 状态与操作：`Sources/Via/Models/PanelModel.swift`、`NetworkDraft.swift`
- 设计令牌：`Sources/Via/DesignSystem/PanelPalette.swift`、`PanelTypography.swift`、`PanelLayout.swift`
- 共享组件：`Sources/Via/DesignSystem/`、`Sources/Via/Components/`
- 三个 Tab：`Sources/Via/Tabs/`
- 首次向导：`Sources/Via/Onboarding/`
- 中英文文案与时长格式化：`Sources/ViaCore/LocalizationManager.swift`
- 面板创建、定位、菜单栏图标：`Sources/Via/main.swift`

修改 UI 时应至少执行：

```bash
swift build
scripts/package-app.sh
codesign --verify --deep --strict --verbose=2 dist/Via.app
```

只有 Command Line Tools 的环境需要用 `scripts/package-app.sh` 内置的 SDK
选择逻辑绕过 SwiftUIMacros 缺失的问题；完整 Xcode 环境可直接 `swift test`。
