# Via UI 设计规范 v2.0（方案 A · 晴空路径仪表盘）

> 适用范围：基于 **MyGo Native UI** 重构后的桌面端（macOS、Windows、Linux）与移动端（Android，并预留 iOS 同构界面）。

---

## 1. 设计目标与相对旧版的 5 项核心革新

Via 的本质只做一件事：**在「首选网络」与「备用网络」之间自动寻找合适路径**。新版设计围绕“**路径感、极简操作、跨端一致**”重构为以下 5 点：

1. **三段变双视图**：精简为 **「主控台」+「设置」** 两个视图，打开面板即可完成看状态、开守护、改网络。
2. **可视化“路径卡”**：顶部把 `主路径 · 首选` 与 `备路径 · 备用` 并排画出，当前哪条路在工作就点亮哪一侧，中间提供一键 `⇄` 互换主备按钮。
3. **点击卡片原地改网**：点选首选或备用网络卡片后，直接在卡片内部展开下拉网络选择列表（首项为一键「使用当前网络」）、手动输入框与密码显示开关，不再跳转到独立表单页。
4. **清爽预设频率**：检查间隔提供 **`15 秒 / 30 秒 / 1 分钟 / 5 分钟 / 自定义`** 分段按钮。
5. **色彩与层级焕新**：采用**晴空冷白 / 午夜深蓝黑**双主题配圆角卡片层次，状态色与主交互色职责清晰分离。

## 2. 色彩规范（浅色 / 深色双主题）

面板默认跟随操作系统浅色 / 深色外观自动切换。

| 令牌用途 | 浅色模式 | 深色模式 | 使用范围 |
| --- | --- | --- | --- |
| 页面底色 (`bg`) | `#F4F7FB` | `#0B1120` | 面板与手机页面最底层背景 |
| 卡片表面 (`surface`) | `#FFFFFF` | `#141D30` | 路径卡、网络卡、设置分组卡、输入框 |
| 次级底色 (`surfaceMuted`) | `#EAF0F8` | `#1E293B` | 未激活按钮底、关闭态开关底、语言胶囊底 |
| 分隔边框 (`border`) | `#E2E8F0` | `#263449` | 1px 卡片描边与内部分割线 |
| 主文字 (`text`) | `#0F172A` | `#F8FAFC` | 标题、当前网络名、正文、开关标签 |
| 次级文字 (`muted`) | `#64748B` | `#94A3B8` | 说明文字、倒计时、未选中标签、次要图标 |
| 主强调色 (`accent`) | `#2563EB` | `#3B82F6` | 主按钮、开启中开关、选中节点边框、扫网文字 |
| 强调文字 (`accentText`) | `#1D4ED8` | `#93C5FD` | 浅背景上的高亮链接、激活标签文字 |
| 在线 / 成功 (`success`) | `#10B981` | `#34D399` | 首选在线脉冲圆点、`已连接` 徽标、授权成功 |
| 备用 / 提醒 (`warning`) | `#F59E0B` | `#FBBF24` | 备用网络运行状态、权限提醒横幅、手动暂停提示条 |
| 暂停 / 错误 (`danger`) | `#EF4444` | `#F87171` | 托盘红点、手动暂停徽标、输入校验报错、退出按钮 |

## 3. 跨平台布局与交互边界

- **桌面端（macOS / Windows / Linux 统一）**：固定宽度 `380px`、高度随页面内容自动适应（`FitContent`，180–720px）的无边框圆角浮出面板（Flyout），左键点击托盘/菜单栏图标锚定弹出；右键菜单精简 3 项：`打开 Via 面板`、`切换运行 / 暂停`、`退出 Via`。
- **移动端（Android，并预留 iOS 同构）**：全屏竖屏自适应布局，顶部与底部正确避让系统安全区（`SafeArea`），底部固定双视图导航栏（`主控台` / `设置`）。

---

## 4. 状态标签与托盘图标（方案一）

- **状态胶囊**：`自动守护中-首选` / `自动守护中-备用` / `自动守护中` / `已暂停` / `缺少权限` / `未配置`。
- **托盘 / 菜单栏图标**：
  - **运行中 · 首选在线**：系统原生 Wi-Fi 图标 + 右下角 **`P`** 角标；
  - **运行中 · 备用在线**：系统原生 Wi-Fi 图标 + 右下角 **`B`** 角标；
  - **运行中 · 其他网络 / 未连接**：纯净系统原生 Wi-Fi 图标；
  - **已暂停**：系统原生 Wi-Fi 图标 + 右下角小号红点。
