# AutoWifi UI 设计与交互规范

## 1. 设计目标

AutoWifi 的设置面板采用深色科技控制台风格，重点不是装饰性渐变，而是让网络状态、主备配置和自动化控制形成稳定、可识别的层级。

核心原则：

- 使用深空蓝黑背景、低对比网格和克制的环境光。
- 每个功能模块拥有固定信号色，不根据临时状态互相换色。
- 业务文案支持简体中文和英文；控制台编号使用稳定的英文系统标识。
- 首页只展示用户做判断所需的语义状态，不直接展示 CoreWLAN 接口名或原始英文运行日志。
- 输入框、按钮、状态标签和帮助面板使用同一套深色内嵌控件语言。

## 2. 面板结构

设置面板固定宽度为 400 点，高度根据 SwiftUI 内容动态计算，最低高度为 360 点。

从上到下包含：

1. 应用标题和顶部快捷操作。
2. `00 / LINK STATUS`：当前连接与运行状态。
3. `01 / PRIMARY`：优先网络 P 配置。
4. `02 / BACKUP`：备用网络 B 配置。
5. `03 / AUTOMATION`：检查间隔和自动切换控制。

模块编号是视觉导航标识：

| 编号 | 标识 | 含义 | 固定信号色 |
| --- | --- | --- | --- |
| `00` | `LINK STATUS` | 当前网络、网络角色和运行状态 | 电光蓝 |
| `01` | `PRIMARY` | 优先网络 P | 青色 |
| `02` | `BACKUP` | 备用网络 B | 紫色 |
| `03` | `AUTOMATION` | 检查频率和自动切换 | 绿色 |

`BACKUP` 描述的是用户正在配置的备用网络，与界面中的“备用网络 (B)”以及菜单栏状态 `B` 一致。`Failover` 更适合描述故障切换行为，不作为该配置模块的名称。

## 3. 当前网络模块

`00 / LINK STATUS` 使用固定电光蓝，不随当前连接到 P、B 或其它网络而变成其它模块的颜色。当前网络角色通过右上角状态标签表达：

- 优先网络
- 备用网络
- 其它网络
- 未连接

模块内第二行包含三个等宽区域：

1. 自动切换：显示运行中或已暂停。
2. 下次检查：运行时显示倒计时；未运行时显示控制模式。
3. 网络发现：点击执行扫描，扫描中显示旋转动画，完成后显示发现的网络数量。

以下底层信息不在首页直接展示：

- `Connected to Priority Network (P). Auto-switch active.` 等原始运行日志。
- `Interface: en1 · Wi-Fi: on` 等接口诊断信息。

这些信息仍可用于内部日志和诊断，但首页改为显示本地化后的网络角色、自动切换状态和检查信息。

## 4. 网络配置模块

`01 / PRIMARY` 与 `02 / BACKUP` 共享结构，但使用不同的固定信号色。

每张卡包含：

- 模块图标、编号和本地化标题。
- 已配置或待配置状态光点。
- 始终可编辑的 SSID 文本框；扫描完成后右侧出现建议网络下拉菜单。
- 密码输入框和明文/密文切换按钮。

控件使用深色内嵌背景、低对比描边和局部信号色，不使用整块高饱和度橙黄或红紫渐变。

## 5. 自动化模块

`03 / AUTOMATION` 包含：

- 当前运行状态光点。
- 检测频率输入（失焦或回车提交）和秒单位。
- 最小 5 秒、最大 3600 秒的检查间隔提示。
- 开启或停止自动切换的主操作按钮。

绿色表示自动化能力。停止操作使用红色警示信号，但不改变整个模块的基础颜色。P 或 B 尚未填写时，主操作按钮禁用，并在下方提示需要补齐两个 SSID。

定位权限被拒绝时，顶部标题下方会出现一条红色警示条，说明无法读取或扫描 Wi-Fi 名称，并提供“打开系统设置”按钮。定位权限尚未决定或已被拒绝时，网络发现按钮会禁用并显示对应状态。

开机启动处于系统“需要批准”状态时，顶部显示橙色警示条和“打开登录项设置”按钮；对应图标也会切换为橙色感叹号状态。

密码写入钥匙串失败时，顶部显示橙色警示条。旧明文副本会保留，应用在下次启动时自动重试迁移。

## 6. 顶部操作与悬浮提示

顶部操作依次为：

- 登录时启动
- 切换语言
- 查看帮助
- 退出应用

每个按钮拥有自己的局部 hover 提示。提示从对应图标下方展开，不再统一固定在面板右上角。最右侧退出按钮的提示向左收口，避免超出窗口边界。

自定义提示替代系统 `.help` Tooltip，防止同时出现两套不同位置和风格的提示。

## 7. 帮助面板

帮助面板尺寸为 350×390 点，沿用主界面的深色科技风格：

- 深空渐变背景和低对比网格。
- `SYS / HELP CENTER` 控制台标识。
- 蓝色信号描边和绿色“仅本机”状态灯。
- 可滚动、可选择的本地化帮助内容。

帮助面板不使用系统默认浅色 Popover 内容背景。

## 8. 本地化边界

跟随语言切换的内容包括：

- 当前网络的特殊状态，如未连接、等待权限、需要定位权限和 Wi-Fi 不可用。
- 网络角色、自动切换状态、扫描状态和扫描结果数量。
- 网络配置标题、配置状态、输入占位文字和自动化设置。
- 顶部 hover 提示和帮助正文。

`00 / LINK STATUS`、`01 / PRIMARY`、`02 / BACKUP`、`03 / AUTOMATION` 和 `SYS / HELP CENTER` 属于短小的控制台导航标识，设计上保持稳定英文；对应的用户可读标题和状态仍会本地化。

## 9. 实现位置

- 主界面、模块组件、颜色、网格、帮助面板和 hover 提示：`Sources/AutoWifi/SettingsView.swift`
- 中英文文案：`Sources/AutoWifiCore/LocalizationManager.swift`
- 面板创建、定位和动态高度：`Sources/AutoWifi/main.swift`

修改 UI 时应至少执行：

```bash
swift test
scripts/package-app.sh
codesign --verify --deep --strict --verbose=2 dist/AutoWifi.app
```
